# C# Basic Math Operations 

Một dự án C# Console Application nhỏ gọn chứa các chương trình tính toán toán học cơ bản. Các đoạn code trong dự án này được tối ưu hóa và có tích hợp sẵn các vòng lặp kiểm tra lỗi đầu vào (Validation) để tránh tình trạng crash chương trình.

##  Các chức năng chính

Dự án bao gồm 2 module xử lý chính:
1. **Tính tổng 3 số**: Yêu cầu người dùng nhập vào 3 số thực. Sử dụng `try-catch` và `TryParse` để liên tục yêu cầu nhập lại nếu dữ liệu đầu vào không phải là số.
2. **Tính chu vi và diện tích hình tròn**: Nhập bán kính `r` với điều kiện `r > 0`. Tính toán chu vi và diện tích với độ chính xác cao bằng hằng số `Math.PI` và làm tròn 2 chữ số thập phân bằng `Math.Round()`.

## Công nghệ sử dụng
- **Ngôn ngữ**: C#
- **Platform**: .NET Console Application
- **Môi trường**: Visual Studio / Visual Studio Code
